
# 💼 Projeto de Monografia — IFPI

Este repositório contém o **projeto de monografia desenvolvido no Instituto Federal do Piauí (IFPI)**, utilizando como base o modelo **abnTeX-IFPI**, adaptado para LaTeX e compatível com editores modernos como VS Code, Overleaf e TeXstudio.

O objetivo deste repositório é **versionar, organizar e documentar** todos os arquivos que compõem o trabalho acadêmico, incluindo capítulos, pré‑textuais, pós‑textuais e configurações.

---

## 📄 Sobre o Modelo Utilizado

Este projeto utiliza uma adaptação do modelo **abnTeX‑IFPI**, originalmente criado por Rafael Madureira Lins de Araújo.  
A versão presente aqui foi atualizada com base:

- no modelo de monografia disponibilizado no site do IFPI  
- no *Manual de Normalização de Trabalhos Acadêmicos do IFPI – 2022*

Além disso, este repositório inclui ajustes e correções para:

- funcionamento em **VS Code**,  
- organização em múltiplos arquivos,  
- compatibilidade com o compilador **pdflatex**,  
- correções internas do ambiente `siglas`,  
- melhorias de codificação (UTF‑8).
