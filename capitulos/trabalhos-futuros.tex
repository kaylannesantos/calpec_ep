\chapter{Trabalhos Futuros}

Diante do exposto sobre o que o sistema tem a oferecer, objetiva-se elencar as melhorias e avanços necessários para otimizar a ferramenta, com o intuito de aprimorar a experiência do usuário. Dentre as melhorias para o sistema, citam-se:

\begin{itemize}
    \item A extração de dados a partir de relatórios oficiais;
    \item O armazenamento dos documentos;
    \item Geração de pdf; e
    \item Integralização com portais jurídicos;
\end{itemize}

Portanto, as melhorias destacadas têm como objetivo aprimorar a Calculadora de Execução Penal, com a finalidade de abranger os usuários finais: o apenado, o sistema de justiça e a sociedade como um todo. Assim, o sistema trabalhado reforça a experiência visual com o sistema, cria uma relação de confiança com a ferramenta de trabalho, concretizando o sistema com o seu diferencial em relação às outras ferramentas expostas.
